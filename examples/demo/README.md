# Demo Evidence Example

Run the guarded workflow documented in [the deterministic demo guide](../../docs/demo/README.md). Runtime evidence is intentionally written only to ignored `.settleflow/demo/evidence.json`; this directory does not contain credentials, financial fixtures, copied logs, or a checked-in output manifest.

The stable public example is the ten named checks and allowlisted evidence shape documented by the guide. Identifiers and timestamps are normalized conceptually rather than committed because the demo proves deterministic business outcomes, not byte-identical randomness.
